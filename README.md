# 🚀 SpaceDrone-Simulator

Java Class를 활용한 간단한 **우주 탐사 드론 시뮬레이터**

## 🛰️ Features

* 사용자 입력으로 배터리 설정
* 행성 위험도 확인
* 배터리 상태에 따른 탐사 여부 판단
* 위험도에 따른 탐사 성공/중단

## 🪐 Structure

```text
src
├─ Main.java
├─ Drone.java
└─ Planet.java
```

## 📚 Java Concepts

* Class
* Object
* Field
* Constructor
* Method
* Object Interaction
